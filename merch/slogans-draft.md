# Slogan drafts — NOT FINAL, NOT REVIEWED, NOT APPROVED FOR PRINT

Every concept below traces to a specific, cited record item already in `../public/data/races.json`. None of these have been legally reviewed. None say "vote for" or "vote against" a candidate — they state a fact and let the shirt be funny about it, which keeps them commentary/satire rather than a false statement of fact. Still get them reviewed before printing (see `../COMPLIANCE.md`).

Deliberately spread across both parties and multiple districts — the point of this project is "receipts, not team jerseys."
